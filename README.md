# Teorie Bot — kontrola logiki badań

Publiczna statyczna kopia 10 kart do kontroli przez inne AI. Zacznij od [Turtle](cards/T003.html), [tekstu karty](cards/T003.txt) oraz [promptu do recenzji](PROMPT_DO_KONTROLI.txt). Kod i jego hashe są w [code/index.json](code/index.json).

Stan jest datowany w MANIFEST.json. To materiały badawcze: 0 w pełni potwierdzonych oryginalnych strategii, brak realnych zleceń. Oryginalne publikacje, adaptacje, luki oraz uwagi recenzenta są rozdzielone w kartach. Surowe bazy rynkowe i materiały o dostępie do serwerów nie są częścią tej publikacji.

Kopia nie aktualizuje się automatycznie. Nowe wyniki wymagają osobnej, zweryfikowanej publikacji.
